# 📊 Fundamentals of Data Science Laboratory (FDSL)

Welcome to my **Fundamentals of Data Science Laboratory (FDSL)** repository. This repository contains all the laboratory programs, assignments, and practical implementations completed as part of the FDSL course during my B.Tech in Information Technology.

## 📚 Course Objectives

* Learn the fundamentals of Data Science.
* Perform data preprocessing and cleaning.
* Analyze datasets using Python.
* Visualize data using charts and graphs.
* Apply statistical techniques and machine learning concepts.

## 🛠️ Technologies Used

* Python
* Jupyter Notebook / VS Code
* NumPy
* Pandas
* Matplotlib
* Seaborn
* Scikit-learn

## 📂 Repository Contents

* Data preprocessing
* NumPy programs
* Pandas DataFrame operations
* Data visualization
* Statistical analysis
* Machine Learning basics
* Laboratory assignments
* Practice datasets

## 🎯 Learning Outcomes

By completing these practicals, I gained hands-on experience in:

* Data manipulation using Pandas
* Numerical computations using NumPy
* Data visualization techniques
* Handling missing values
* GroupBy and Pivot Table operations
* Exploratory Data Analysis (EDA)
* Basic Machine Learning workflows
